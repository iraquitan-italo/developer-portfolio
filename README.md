# 📖 Sobre o projeto

O **Developer Portfolio** é um site responsivo criado para reunir informações profissionais em um único lugar.

A aplicação apresenta dados como habilidades técnicas, projetos, experiências profissionais, formações acadêmicas e formas de contato, carregando essas informações dinamicamente por meio de um arquivo JSON.

O objetivo é oferecer uma página moderna e organizada para destacar o perfil profissional de um desenvolvedor.
